# pmax-sentry CLI (`pmax-audit`)

An open-source, local command-line tool for Google Ads Performance Max delivery observability.

## Key Capabilities
- Inspect PMax campaign totals and daily performance.
- Segmented delivery reporting across channels (Search, Partners, Display, YouTube, Discover, Gmail, Maps) and format dimensions (product feed, video).
- Strict reconciliation check between campaign totals and segmented reporting.
- Search-demand insight reports strictly separated from cost metrics.
- CSV and JSON exports with complete metadata (currency, timezone, API version, coverage status).
- Safe dry-run previews before exporting large datasets.
